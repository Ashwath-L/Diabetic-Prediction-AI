Metric Explanations

Accuracy

The proportion of total predictions that were correct. Useful when classes are balanced. \[\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}\]

Precision

Out of all patients predicted as diabetic, how many actually were diabetic. High precision minimizes false alarms (False Positives). \[\text{Precision} = \frac{TP}{TP + FP}\]

Recall (Sensitivity)

Out of all actual diabetic patients, how many were correctly detected. High recall minimizes missed diagnoses (False Negatives). \[\text{Recall} = \frac{TP}{TP + FN}\]

Confusion Matrices

Understanding the Confusion Matrix

True Negative (TN)

The model correctly predicted that a patient is Non-Diabetic.

True Positive (TP)

The model correctly predicted that a patient is Diabetic.

False Positive (FP) - Type I Error

The model incorrectly predicted that a healthy patient is Diabetic.

False Negative (FN) - Type II Error

The model incorrectly predicted that a diabetic patient is Non-Diabetic.
