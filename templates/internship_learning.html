15-Day Internship Mapping

Overview of how the Artificial Intelligence Internship syllabus topics are implemented and demonstrated in this project

Day 1 (Syllabus Days 1 + 2): Introduction to AI & Fundamentals

Topics: Definition of AI, History and Evolution, Types of AI, Intelligent Agents, Problem Solving, Search Algorithms, Knowledge Representation.

Demonstration: Explained conceptually on the AI Concepts and About pages. The diabetes predictor represents a goal-based intelligent agent mapping inputs (clinical metrics) to actions (class predictions).

Day 2 (Syllabus Days 3 + 4): Python for AI & Data Handling with NumPy

Topics: Variables, Data Types, Control Structures, Functions, Modules, NumPy Arrays, Array Operations, Mathematical Computations.

Demonstration: Built using clean Python modules under src/. NumPy arrays are used for data manipulation, replacing invalid zeros (np.nan), and formatting inputs for TensorFlow model predictions.

Day 3 (Syllabus Days 5 + 6): Pandas & Data Visualization

Topics: Loading datasets, DataFrames, cleaning, filtering, aggregation, statistical summary, Matplotlib charts (histograms, bar plots, scatter plots).

Demonstration: Loaded the dataset in src/data_analysis.py using Pandas. Generated class distribution bar charts, correlation matrix heatmaps, and feature distributions using Matplotlib, rendered on the Data Analysis page.

Day 4 (Syllabus Days 7 + 8): AI Development Environment & ML Intro

Topics: Jupyter Notebook, Google Colab, Supervised vs Unsupervised Learning, Machine Learning classification problem formulation.

Demonstration: Developed a complete notebooks/diabetes_prediction.ipynb notebook that runs step-by-step in Jupyter/Colab. Formulated the main task as a Supervised Classification problem since known Outcome labels (0/1) are present.

Day 5 (Syllabus Days 9 + 10): Data Preprocessing & Feature Engineering

Topics: Handling missing values, feature scaling (StandardScaler), feature selection, data transformation, importance of features.

Demonstration: Replaced invalid zeros and imputed them with SimpleImputer, scaled attributes using StandardScaler in src/preprocessing.py. Created interaction feature Glucose_Age_Interaction = Glucose * Age and analyzed feature correlation in src/feature_engineering.py.

Day 6 (Syllabus Days 11 + 12): Regression & Classification

Topics: Linear Regression, Multiple Linear Regression, Logistic Regression, K-Nearest Neighbors (KNN), Decision Trees.

Demonstration: Implemented Simple and Multiple Linear Regression separately in src/regression.py to predict continuous BloodPressure. Implemented three classification algorithms (Logistic Regression, KNN, Decision Tree) in src/classification.py to solve the main classification task.

Day 7 (Syllabus Days 13 + 14): Model Evaluation & Clustering

Topics: Accuracy, Precision, Recall, Confusion Matrix (TP, TN, FP, FN), K-Means Clustering, Hierarchical Clustering.

Demonstration: Computed performance metrics on test splits in src/evaluation.py and plotted confusion matrices. Implemented K-Means and Hierarchical Clustering on Glucose and BMI in src/clustering.py to demonstrate unsupervised data-driven grouping (using a fixed K=3).

Day 8 (Syllabus Days 15 + 16): Deep Learning & ANN

Topics: Neural Network concepts, Perceptron, Activation Functions (ReLU, Sigmoid), ANN Architecture, Forward Propagation, Backpropagation, Training.

Demonstration: Designed a multi-layer feedforward network using TensorFlow/Keras in src/neural_network.py. The model uses Dense layers, ReLU activations in hidden layers, and Sigmoid at the output, trained and evaluated on the diabetes dataset.

Day 9 (Syllabus Days 17 + 18): CNN & NLP

Topics: CNN architecture, Image Classification, Natural Language Processing, text processing, tokenization, sentiment analysis.

Demonstration: Configured as educational concept modules on the AI Concepts page. Explains CNN structures (convolution, pooling) and NLP tokenization steps, documenting why CNNs are not suitable for this tabular dataset.

Day 10 (Syllabus Days 19 + 20): AI Libraries & Computer Vision

Topics: Scikit-Learn, TensorFlow, Keras, NumPy, Pandas, Matplotlib, Image Recognition, Object Detection, Face Recognition.

Demonstration: Leveraged Scikit-Learn (models, imputer, scaler), TensorFlow/Keras (ANN building), and Matplotlib (visualizations). Explained Computer Vision algorithms conceptually on the AI Concepts page.

Day 11 (Syllabus Days 21 + 22): Recommendation Systems & AI Ethics

Topics: Collaborative vs Content-Based Filtering, Bias, Fairness, Transparency, Privacy, Ethical practices, Disclaimers.

Demonstration: Explained recommendation algorithms (collaborative/content) conceptually. Dedicated the Ethics page to analyzing Bias, Fairness, Privacy, and Transparency, including a prominent medical disclaimer on the prediction and results views.

Day 12 (Syllabus Days 23 + 24): Generative AI & Prompt Engineering

Topics: Large Language Models, AI chatbots, prompt writing techniques, response optimization, practical exercises.

Demonstration: Outlined Generative AI LLM architectures on the AI Concepts page. Includes a prompt engineering exercise showing how to craft structured prompts to format medical metrics into markdown.

Day 13 (Syllabus Days 25 + 26): AI Project Lifecycle & Model Deployment

Topics: Project Lifecycle steps, model deployment concepts, Flask deployment implementation.

Demonstration: Illustrated the complete project lifecycle on the About page. Deployed the trained classifiers via a Flask python web server (app.py) enabling real-time classification prediction.

Day 14 (Syllabus Days 27 + 28): Industry Applications & Project Development

Topics: AI in healthcare, finance, manufacturing, and smart systems; integrated project development.

Demonstration: Discussed industry applications on the About page. Developed the complete modular code codebase integrating python modules, visualization, models, and Flask deployment.

Day 15 (Syllabus Days 29 + 30): Validation, Presentation & Conclusion

Topics: Model testing, performance evaluation, error analysis, optimization, future scope.

Demonstration: Tested models on validation splits, conducted comparative error analysis, and summarized learnings and future scope on the About page.
