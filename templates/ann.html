Core Deep Learning Concepts

Theoretical breakdown of neural network topics from the internship syllabus

Perceptron & Neurons

The Perceptron is the fundamental building block of neural networks. It takes inputs \(x_i\), multiplies them by weights \(w_i\), sums them with a bias \(b\), and passes the result through an activation function: \[z = \sum_{i=1}^{n} w_i x_i + b\]

An Artificial Neural Network (ANN) connects multiple layers of these perceptrons to model complex relationships.

Forward & Backpropagation

Forward Propagation: Input features flow forward through the layers. Each layer calculates activation values until the output node generates a prediction.

Backpropagation: Calculates the error at the output using the loss function, and sends this error backward through the network using the chain rule (derivatives) to update the weights and biases to minimize loss.

Activation Functions

Activation functions decide if a neuron should fire. We use two key functions:

  • ReLU (Rectified Linear Unit): \(f(z) = \max(0, z)\). Used in hidden layers to avoid the vanishing gradient problem.
  • Sigmoid: \(\sigma(z) = \frac{1}{1 + e^{-z}}\). Squashes output into a range of 0 to 1, perfect for binary classification probability mapping.
