The AI Project Lifecycle

1. Problem Identification & Objectives

Defining the medical classification task: predicting if a patient belongs to the diabetic or non-diabetic class based on clinical history attributes.

2. Data Collection

Acquiring the standard Pima Indians Diabetes Dataset from the National Institute of Diabetes and Digestive and Kidney Diseases.

3. Data Analysis & Cleaning

Using Pandas to read files, identify missing values, locate invalid zero values (Glucose, Blood Pressure, BMI, etc.), and plot distributions with Matplotlib.

4. Data Preprocessing & Feature Engineering

Replacing zeros with NaN, imputing using column medians, and scaling features using StandardScaler. Engineering the Glucose * Age interaction feature.

5. Model Development & Evaluation

Training Logistic Regression, KNN, Decision Tree, and Keras ANN. Evaluating performance using Accuracy, Precision, Recall, and Confusion Matrices.

6. Model Deployment

Saving the trained models and preprocessors (pickles & keras files) and launching a lightweight Flask web application to serve predictions.

Future Scope of AI

  • 📈 Dataset Scaling: Train models on larger, multi-hospital, multi-ethnic datasets to improve generalization.
  • 🧬 Multi-Omics: Integrate genomic, proteomic, and metabolic markers alongside basic clinical parameters.
  • ⌚ Real-time Streams: Connect continuous glucose monitor (CGM) IoT streams to trigger warnings before hyperglycemic onset.
