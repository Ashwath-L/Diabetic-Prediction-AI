Diabetes Prediction using Artificial Intelligence

Educational AI/ML Internship Capstone Project

Project Overview

This project is an educational Artificial Intelligence system designed to predict whether an individual belongs to the diabetic or non-diabetic class. Using the standard Pima Indians Diabetes Dataset, we demonstrate core concepts covered in the 15-day AI internship syllabus, including Python, Pandas, NumPy, Matplotlib, Supervised Machine Learning (classification models), Unsupervised Learning (clustering), and Deep Learning (Artificial Neural Networks with TensorFlow/Keras).

The project pipeline is split into logical stages representing the complete AI Project Lifecycle: data collection, cleaning, preprocessing, feature engineering, model training, evaluation, and deployment using a lightweight Flask interface.

Dataset Characteristics

The Pima Indians Diabetes Dataset contains numerical health features from female patients of Pima Indian heritage. Features include:

  • 🩺 Pregnancies: Number of times pregnant
  • 🩺 Glucose: Plasma glucose concentration (2 hours in GTT)
  • 🩺 BloodPressure: Diastolic blood pressure (mmHg)
  • 🩺 SkinThickness: Triceps skin fold thickness (mm)
  • 🩺 Insulin: 2-Hour serum insulin (mu U/ml)
  • 🩺 BMI: Body mass index (weight in kg/(height in m)^2)
  • 🩺 DiabetesPedigreeFunction: Diabetes pedigree score
  • 🩺 Age: Age in years

The target output is Outcome (0 for Non-Diabetic, 1 for Diabetic).
